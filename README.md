# משחקים — אפליקציית פעילויות לגיל הרך

אפליקציה ויזואלית לאייפד: מסך בית עם סוגי משחק, והתאמה/בחירה/רצף עם ערכות. צלילים קצרים ורכים, עם כפתור השתקה.

## למי זה מיועד
לילד בן ~4, לא־מילולי, על הרצף האוטיסטי. אין צורך בדיבור — עונים בגרירה בלבד (לחיצה בלי גרירה לא סוגרת תשובה). ניווט בין מסכים נשאר בלחיצה.
ממשק בעברית (RTL), כפתורים גדולים, בלי טיימר. שלושה צלילים קצרים: נקישה רכה על כפתורי ניווט, צלצול קצר על תשובה נכונה ועל מסך הסיום, ו«אופס» רך כשמניחים על היעד הלא־נכון. גרירה באוויר או שחרור מחוץ ליעד — בלי צליל. כפתור הרמקול למטה משמאל משתיק וזוכר את הבחירה. הקול נפתח במגע הראשון (לחיצה או גרירה), כדי שספארי באייפד ינגן.

## מסך הבית
חמישה סוגי פעילות:
1. **התאמה** — פעיל (בוחרים ערכה ומשחקים)
2. **בחירה** — פעיל (חיות · מה שייך? · וגם מה לא שייך?)
3. **רצף** — פעיל (ערכה אחת: יום של כלב)
4. **קטגוריות** — פעיל (חיות · כלי תחבורה · וגם פירות · ירקות)
5. **חידון ויזואלי** — פעיל (חיות · חלק או צללית · וגם צלליות)

## התאמה — ערכות
### חיות
- חתול → קערת חלב
- כלב → עצם
- ציפור → קן
- דג → אקווריום

### כלי תחבורה
- מכונית → מוסך
- סירה → מים
- מטוס → ענן / שמיים
- רכבת → פסים

### צורות
- עיגול → צללית עיגול
- ריבוע → צללית ריבוע
- משולש → צללית משולש
- כוכב → צללית כוכב

### צבעים
- כדור אדום → כתם אדום
- דג כחול → כתם כחול
- שמש צהובה → כתם צהוב
- עלה ירוק → כתם ירוק

### אוכל · למקום
- תפוח → סל פירות
- בקבוק חלב → מקרר
- לחם → טוסטר
- בקבוק מים → כוס

גרירה עם סף 8px, מאזיני pointer על document, ו־ghost בחריץ. לחיצה בלי גרירה לא מתאימה.

## בחירה — ערכות
### חיות · מה שייך?
תמונת שאלה גדולה (אזור ההנחה) + 3 כרטיסי בחירה (אחת נכונה).
גרירה אל תמונת השאלה: ירוק אם נכון, רעידה עדינה אם הכרטיס הלא־נכון הונח עליה. לחיצה בלי גרירה לא עונה.
~6 סיבובים ואז חגיגה · עוד פעם · ערכות · בית.
דוגמאות: חתול→חלב (בין עצם/קן); קערה→חתול (בין כלב/ציפור).

### מה לא שייך?
4 כרטיסים: 3 מאותה קבוצה + 1 שונה. גוררים את השונה אל סימן השאלה.
לחיצה בלי גרירה לא עונה. 6 סיבובים קלים.
דוגמאות: 3 חיות + מכונית; 3 פירות + נעל; 3 כלי תחבורה + דג; 3 ירקות + כדור; כוס/צלחת/כף + ציפור; 3 צעצועים + תפוח.

## רצף — ערכות
### יום של כלב
**3 שלבים** (הוקטן לקושי רך): מתעורר → אוכל → ישן.
- אריחים גדולים יותר (3 עמודות)
- רצועת רמז ממוספרת למעלה (תמונות קטנות ודהויות של הסדר הנכון)
- החריץ הראשון מלא מראש (מתעורר)
- משוב שגוי רך בלבד (רעידה עדינה)
- גרירה להנחה בחריץ (לחיצה בלי גרירה לא מניחה)

נכסים מלאים (5) עדיין ב־`assets/` (כולל טיול/משחק) אם ירצו להרחיב שוב בהמשך.
אין עבודת רצף נוספת אחרי זה לפי בקשת המשוב.

## קטגוריות — ערכות
### חיות · כלי תחבורה
שתי קופסאות גדולות: **חיות** / **כלי תחבורה**.
6 כרטיסים (חתול, כלב, ציפור · מכונית, סירה, רכבת) — גרירה לקופסה. לחיצה בלי גרירה לא משייכת.
שגיאה רכה (רעידה), ירוק כשנכון, חגיגה בסיום.
איורי GenerateImage מהערכות הקיימות (לא clipart).

### פירות · ירקות
שתי קופסאות: **פירות** / **ירקות**.
6 כרטיסים (תפוח, בננה, תפוז · גזר, מלפפון, ברוקולי) — גרירה לקופסה. לחיצה בלי גרירה לא משייכת.

## חידון ויזואלי — ערכות
### חיות · חלק או צללית (קל)
רמז גדול: **זום על חלק** (אוזן/אף/מקור/זנב) או **צללית** של חיה.
3 כרטיסי חיות מלאים גדולים — גרירה אל הרמז.
ירוק אם נכון, רעידה עדינה אם הכרטיס הלא־נכון הונח על הרמז. לחיצה בלי גרירה לא עונה. ~5 סיבובים ואז חגיגה.
איורים מהכרטיסים הקיימים (חיתוך זום + צללית ב־CSS).

### צלליות · חיות (קל)
ערכה נפרדת: צללית אמיתית של חיה (פיל, ארנב, ג׳ירפה, ברווז, צב) ו־3 חיות מלאות.
גוררים את החיה שמתאימה אל הצללית. לחיצה בלי גרירה לא עונה. 5 סיבובים.

## ניווט
בית → סוג → ערכות → משחק → כפתורי חזרה.
בסיום: **עוד פעם** / ערכות / בית.

## איך לפתוח

### שרת מקומי (מומלץ לאייפד באותה רשת)
```bash
cd ~/Desktop/animal-match
python3 -m http.server 8766 --bind 0.0.0.0
```
באייפד / במק:
```
http://127.0.0.1:8766/
```
או `http://<IP-של-המק>:8766/`

לחיצה כפולה על `index.html` ב־Safari.

## קבצים
- `index.html` — האפליקציה כולה
- `assets/` — תמונות הערכות (חיות + כלי תחבורה + צורות + צבעים + אוכל למקום + מה לא שייך + פירות וירקות + צלליות חיות + רצף + חידון) וצלילים (`sfx-tap.wav`, `sfx-success.wav`, `sfx-wrong.wav`)
- `gen/make_sfx.py` — מחולל שלושת הצלילים
- `gen/make_dog_day.py` — מחולל איורי הרצף
- `gen/make_quiz_details.py` — מחולל חיתוכי זום לחידון
- `gen/make_shapes_colors.py` — מחולל איורי צורות וצבעים
