# משחקים — אפליקציית פעילויות לגיל הרך

אפליקציה ויזואלית ושקטה לאייפד: מסך בית עם סוגי משחק, והתאמה/בחירה/רצף עם ערכות.

## למי זה מיועד
לילד בן ~4, לא־מילולי, על הרצף האוטיסטי. אין צורך בדיבור — רק מגע (גרירה או לחיצה).
ממשק בעברית (RTL), כפתורים גדולים, בלי קול ובלי טיימר.

## מסך הבית
חמישה סוגי פעילות:
1. **התאמה** — פעיל (בוחרים ערכה ומשחקים)
2. **בחירה** — פעיל (ערכה אחת: חיות · מה שייך?)
3. **רצף** — פעיל (ערכה אחת: יום של כלב)
4. **קטגוריות** — פעיל (ערכה אחת: חיות · כלי תחבורה)
5. **חידון ויזואלי** — פעיל (ערכה אחת: חיות · חלק או צללית)

## התאמה — ערכות
### חיות
- חתול → קערת חלב
- כלב → עצם
- ציפור → קן
- דג → אקווריום

### כלי תחבורה
- מכונית → מוסך
- סירה → מים
- מטוס → ענן / שמיים
- רכבת → פסים

### צורות
- עיגול → צללית עיגול
- ריבוע → צללית ריבוע
- משולש → צללית משולש
- כוכב → צללית כוכב

### צבעים
- כדור אדום → כתם אדום
- דג כחול → כתם כחול
- שמש צהובה → כתם צהוב
- עלה ירוק → כתם ירוק

גרירה עם סף 8px, מאזיני pointer על document, ו־ghost בחריץ.

## בחירה — ערכות
### חיות · מה שייך?
תמונת שאלה גדולה + 3 כרטיסי בחירה (אחת נכונה).
לחיצה לבחירה: ירוק אם נכון, רעידה עדינה אם לא; אחר כך סיבוב הבא.
~6 סיבובים ואז חגיגה · עוד פעם · ערכות · בית.
דוגמאות: חתול→חלב (בין עצם/קן); קערה→חתול (בין כלב/ציפור).

## רצף — ערכות
### יום של כלב
**3 שלבים** (הוקטן לקושי רך): מתעורר → אוכל → ישן.
- אריחים גדולים יותר (3 עמודות)
- רצועת רמז ממוספרת למעלה (תמונות קטנות ודהויות של הסדר הנכון)
- החריץ הראשון מלא מראש (מתעורר)
- משוב שגוי רך בלבד (רעידה עדינה)
- גרירה או לחיצה להנחה בחריץ הריק הבא

נכסים מלאים (5) עדיין ב־`assets/` (כולל טיול/משחק) אם ירצו להרחיב שוב בהמשך.
אין עבודת רצף נוספת אחרי זה לפי בקשת המשוב.

## קטגוריות — ערכות
### חיות · כלי תחבורה
שתי קופסאות גדולות: **חיות** / **כלי תחבורה**.
6 כרטיסים (חתול, כלב, ציפור · מכונית, סירה, רכבת) — גרירה או לחיצה לקופסה.
שגיאה רכה (רעידה), ירוק כשנכון, חגיגה בסיום.
איורי GenerateImage מהערכות הקיימות (לא clipart).

## חידון ויזואלי — ערכות
### חיות · חלק או צללית (קל)
רמז גדול: **זום על חלק** (אוזן/אף/מקור/זנב) או **צללית** של חיה.
3 כרטיסי חיות מלאים גדולים — לחיצה לבחירה.
ירוק אם נכון, רעידה עדינה אם לא; ~5 סיבובים ואז חגיגה.
איורים מהכרטיסים הקיימים (חיתוך זום + צללית ב־CSS).

## ניווט
בית → סוג → ערכות → משחק → כפתורי חזרה.
בסיום: **עוד פעם** / ערכות / בית.

## איך לפתוח

### שרת מקומי (מומלץ לאייפד באותה רשת)
```bash
cd ~/Desktop/animal-match
python3 -m http.server 8766 --bind 0.0.0.0
```
באייפד / במק:
```
http://127.0.0.1:8766/
```
או `http://<IP-של-המק>:8766/`

> פורט **8765** שמור ל־ipracticom — לא לגעת.

### קובץ מקומי
לחיצה כפולה על `index.html` ב־Safari.

## קבצים
- `index.html` — האפליקציה כולה
- `assets/` — תמונות הערכות (חיות + כלי תחבורה + צורות + צבעים + רצף יום של כלב + קטגוריות + חידון ויזואלי)
- `gen/make_dog_day.py` — מחולל איורי הרצף
- `gen/make_quiz_details.py` — מחולל חיתוכי זום לחידון
- `gen/make_shapes_colors.py` — מחולל איורי צורות וצבעים
